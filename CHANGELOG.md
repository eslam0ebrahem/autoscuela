# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-03-13

### Added
- New `MobileNav` component for improved mobile navigation and reachability.
- Glassmorphic design system applied across all major screens.
- Smooth scale and fade animations for page transitions and card interactions.

### Changed
- Redesigned Dashboard with a "mission control" layout, consolidated stats, and actionable study cards.
- Enhanced Exam Interface with a mobile-first layout, large touch targets, and persistent progress tracking.
- Modernized Settings page with intuitive profile and theme management.
- Unified Login and Register pages with a premium, consistent aesthetic.
- Upgraded Flashcards experience with better flip animations and larger touch areas.
- Refactored `AppShell` and `Navbar` to support the new mobile navigation strategy.

### Fixed
- Updated default MongoDB database name to `autoscuela_v4` for consistency.
- Removed invalid empty directory `{answer,submit}` from API routes.
- Improved spacing and responsiveness across all core application screens.
